# Game theory -> Drosophila

| Domain concept | Fly correspondence | Strength | Experimental translation |
|---|---|---|---|
| opponent / strategic agent | another fly whose behavior changes the focal fly's outcomes | functional | use closed-loop opponent policies rather than prerecorded stimuli where possible |
| repeated game | repeated social encounters with history-dependent behavior | functional | preserve encounter history and test policy change |
| winner/loser effect | prior fight outcome can alter later dominance/aggression in male flies | functional | map reputation/history state to prior social outcome; test causal dependence |
| competition for scarce resource | aggression around food/territory/mates | functional | resource availability becomes an environmental state, not an abstract payoff table only |
| signaling | courtship song, pheromones and other social signals affecting another agent | functional | allow action to alter opponent sensory state |
| costly signaling | courtship/aggressive actions consuming time/energy and exposing risk | operational_analogy | price actions through explicit energetic/opportunity costs |
| coordination | mutual adjustment of behavior to another fly's actions | operational_analogy | closed-loop dyadic tasks; avoid equating any synchrony with cooperation |
| bargaining | no canonical direct equivalent established here | metaphor_only | use only as an abstract framing unless supported by specific behavior literature |
| mixed strategy | stochastic action selection conditioned on state | operational_analogy | measure action distributions; do not infer game-theoretic optimality from variability |
| equilibrium | stable distribution of behaviors under repeated interaction | operational_analogy | empirical stationary behavior is not automatically Nash equilibrium |
| reputation | history-dependent opponent response | operational_analogy | require observable memory/history channel and behavioral effect |
| mechanism design | engineered environment that changes incentives of multiple flies | metaphor_only | valid experimental design analogy, not a biological mechanism |

Especially useful biological anchors are aggression/dominance, courtship, mate choice,
resource competition and closed-loop social feedback.
