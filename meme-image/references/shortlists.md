# meme-image — known-good template shortlist

Reference file for the `meme-image` skill. This is a **non-exhaustive**
memory aid of templates commonly useful for essay-style posts, grouped
by function. Always treat the live API catalog as canonical — read it
before choosing a template, per SKILL.md.
